# Project credits

This public repository is a newly written reference implementation maintained by [Akshat Agrawal](https://github.com/Akshat3004).

It is based on the conceptual ASR, translation, and speech-synthesis stages of an earlier collaborative research prototype. The original team implementation and audiovisual samples are not included in this public repository. Individual contributions to the original work are not determined from the available archive.

The baseline also relies on third-party packages (Whisper, deep-translator, gTTS, FFmpeg), each subject to its own license and terms.
